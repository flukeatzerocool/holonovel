# Knowledge Base Index

Cached research findings for spec-engineering-loop sessions. Entries are
Markdown files organized by domain. Check freshness before trusting cached
data — stale entries trigger a fresh web search or spec re-read.

**Freshness rules:**
- `web/` entries expire 30 days after source date
- `spec/` entries expire when the spec section's REQ count changes
- `implementation/` entries expire 14 days after source date (code changes faster than web)

**Conventions:**
- One topic per file
- First line: `# Title` with topic tags on next line
- Each entry carries `**Sourced:** YYYY-MM-DD | **Expires:** YYYY-MM-DD`
- Source URLs preserved in a `## Sources` section
