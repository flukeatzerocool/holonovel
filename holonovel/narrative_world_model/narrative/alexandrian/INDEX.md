## Module: adventure_advice (4 items)

### `axn-node-based-design` — MEDIUM
Category: adventure_templates
Content: Node-based scenario design replaces linear plots with connected locations. Each
node is a discrete location where something happens. Connections between nodes are
discovered through player investigation — the GM does not pre-decide the path. The node
map is preparation; the route through it is play. Maps to Holonovel's world-model room
system and adventure structure per REQ-079.

### `axn-three-clue-rule` — MEDIUM
Category: adventure_templates
Content: For any conclusion the players must reach, place three clues. Clues should be
redundant (any one leads to the conclusion), diverse (different types: physical evidence,
witness testimony, document), and discoverable without specific skill checks. If players
miss one, they can find another. Maps to Holonovel's lore entry trigger and secret
revelation system per REQ-083 and REQ-234.

### `axn-mystery-structure` — HIGH
Category: scenario_starters
Content: Mystery adventure structure: (1) establish the crime, (2) seed the three clues
that point to the solution, (3) populate locations where each clue can be found, (4)
connect locations with passive clue breadcrumbs, (5) prepare the confrontation scene.
Each node should offer multiple clues pointing to multiple nodes — a web, not a chain.

### `axn-reactive-world` — MEDIUM
Category: scenario_starters
Content: The game world reacts to player actions and inaction. Advance faction clocks
when players choose one path over another. Create off-screen consequences for
abandoned threads. Maps to Holonovel's world reactivity system per REQ-233a and
faction progress clocks per REQ-233.

## Module: lore_templates (3 items)

### `axn-three-clue-seeding` — MEDIUM
Key: three_clue_rule, triggers: [investigation, mystery, clue, evidence, discovery]
Content: For each conclusion, seed three lore entries: one physical (object, marking,
pattern), one social (witness, rumor, accusation), one environmental (location detail,
historical context). When a lore trigger fires, the relevant entry surfaces in the
scene. This creates discoverable knowledge without railroading.

### `axn-node-connections` — MEDIUM
Key: node_connections, triggers: [investigate, search, explore, examine, travel]
Content: Each location node carries clues to 2-3 connected nodes. When players search a
lore-triggered location, surface the connecting clues as triggered lore entries. The
connections form a discoverable map — no single path, no dead ends.

### `axn-faction-web` — LOW
Key: faction_web, triggers: [faction, intrigue, politics, alliance, betrayal]
Content: Map faction relationships as an intrigue web. Each faction has: a public goal, a
secret goal, an active scheme (tracked via countdown), and relationships with 2-3 other
factions. When a faction's scheme clock fills, update the web — alliances shift, secrets
are revealed, new schemes begin. Maps to Holonovel's faction system per REQ-233 and
relationship system per REQ-236.
