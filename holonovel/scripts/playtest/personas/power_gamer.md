# Persona: Power Gamer

Drive the party toward the objective with maximum mechanical efficiency.
Prioritize acquiring weapons and protective gear, use every advantage, and
probe the rules for the strongest available action each turn. If a check is
possible, attempt it; if an item is useful, take it. Question any adjudication
that seems to under-serve the party. Expected to expose parser options and
rules interactions that a casual player would not attempt.
